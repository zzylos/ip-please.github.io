# IP, PLEASE

A pixel-art mini game in the style of Papers, Please. You won the October Labor Lottery and have been assigned to the Ministry of Alignment's UTC+8 Checkpoint as entry inspector Claude. You have exactly one job: catch the travelers who are pretending to be American.

This is the English translation. The original Chinese version is playable at <https://ip-please.github.io>.

- 6 days of story + two endings, about 30 minutes in total, with an automatic save every day
- Drag the papers with your finger (phone in landscape) or the mouse (computer)
- A plain static web page that loads nothing from outside; after downloading the repository you can also just double-click `index.html` to play

## How to play

Call the next traveler → drag their papers onto the desk → check them against the Constitution → stamp → hand the papers back.

| Day | New rule / new tool |
|---|---|
| 1 | Only let in IPs from supported regions |
| 2 | Time zone and language must match the IP; the quiz and detaining |
| 3 | Account card: payment card, billing address, phone number |
| 4 | X-ray scan for background processes; the slang fast lane |
| 5 | Majority Chinese-owned companies; the distillation army |
| 6 | George, final form, and the very last traveler |

Some jokes depend on Chinese text on purpose: an impostor might slip a Chinese word or full-width punctuation into their English, and the quiz uses famous Chinese phrases that only a Chinese speaker would finish without thinking. Those lines stay in Chinese, with a short English explanation in brackets.

## Files

| Path | Contents |
|---|---|
| `index.html` | The page |
| `main.js` | Scene switching, input, main loop |
| `booth.js` | The inspection booth: papers, stamps, inspect mode, the quiz, X-ray |
| `events.js` | Slang fast lane, distillation army, the chat ban, the endings |
| `screens.js` | Intro, newspaper, end-of-day summary, credits, saving |
| `data.js` | The script: each day's travelers, newspaper, random passers-by |
| `docs.js` | Documents: passport, device card, account card, the Constitution |
| `gfx.js` / `sfx.js` | Pixel drawing / sound synthesis (all generated live, no audio files) |
| `assets.js` | Pre-rendered characters, backgrounds and glyph atlas (generated by `tools/build_assets.py`, don't edit by hand) |
| `tools/` | Asset tools: `pp/` draws the characters and scenes, `assets/fonts/` holds the pixel fonts |

## Changing text and rebuilding assets

After changing any in-game text (every character the game uses has to be in the glyph atlas) or how a character is drawn, regenerate `assets.js`:

```bash
pip install -r tools/requirements.txt
python tools/build_assets.py
```

Local preview: run `python -m http.server` in the repository root and open <http://localhost:8000>.
